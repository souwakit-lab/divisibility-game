# 整除性：數字守城戰

學生答題頁與教師大屏，內容分為三個程度：

- 程度一：判斷能否被 2、5、10（隨機一種）整除
- 程度二：判斷能否被 3 整除
- 程度三：同時判斷能否被 2、5、10、3 整除

## 頁面

- `index.html`：學生答題
- `dashboard.html`：教師大屏
- `formula.html`：公式和代入法六關練習（本機進度版）

資料透過 `apps-script/Code.gs` 寫入獨立的 Google Sheet。若 `config.js` 尚未填入 Apps Script 網址，網站會使用瀏覽器本機資料，方便預覽。

## 技能預覽

執行 `python3 -m http.server 8765`，開啟 `http://localhost:8765/?preview=1`。預覽自動進場，不讀寫本機成績或遠端資料。四個技能按鈕可免費試放；答對自動出招，連答 3 / 5 題強化特效，程度三觸發四元素連擊。音效預設關閉，可在戰場右上角開啟。

## 裂界戰技

技能已重新設計為斷空拔刃、獄焰墜星、零界脈衝、虛空絞殺（各 2.2 秒），每五連答觸發天隙劍陣（3.8 秒）。四項判斷全對施放虛空絞殺；傷害仍由原答題規則決定。新技能以 Canvas 即時繪製，不載入舊金龍素材。

五式同階更新：所有技能統一為 4 秒，已取消終結技與五連答觸發區分。單項題目依除數施放對應技能，四項題全對施放天隙劍陣。連答仍保留原有計分規則。
